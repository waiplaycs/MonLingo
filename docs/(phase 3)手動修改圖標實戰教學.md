# 手動修改工具條圖標 - 實戰教學

> 讓我們一步步教您如何修改 MonLingo 工具條的圖標

## 🎯 實際操作 - 修改播放按鈕為愛心

### 步驟 1: 備份原始檔案

首先，我們備份原始檔案以防萬一：

1. 複製 `MainBarWindow.xaml` 為 `MainBarWindow.xaml.backup`
2. 或者記住原始的播放圖標路徑數據：
   ```
   M6 4L20 12L6 20V4Z
   ```

### 步驟 2: 打開編輯檔案

使用任何文字編輯器打開：
```
MonLingo2\src\MonLingo.Core\View\Windows\MainBarWindow.xaml
```

### 步驟 3: 找到播放圖標定義

在檔案中找到這一行（約第 16 行）：
```xml
<Geometry x:Key="IconPlay">M6 4L20 12L6 20V4Z</Geometry>
```

### 步驟 4: 替換為愛心圖標

將原始路徑替換為愛心路徑：
```xml
<Geometry x:Key="IconPlay">M20.84 4.61A5.5 5.5 0 0 0 16.5 2.5C14.76 2.5 13.5 3.5 12 5C10.5 3.5 9.24 2.5 7.5 2.5A5.5 5.5 0 0 0 3.16 4.61C1.04 6.73 1.04 10.27 3.16 12.39L12 21.35L20.84 12.39C22.96 10.27 22.96 6.73 20.84 4.61Z</Geometry>
```

### 步驟 5: 保存並測試

1. 保存檔案 (`Ctrl + S`)
2. 重新建置專案：
   ```bash
   dotnet build src/MonLingo.Core/MonLingo.Core.csproj
   ```
3. 運行應用程式查看效果

## 🛠️ 快速修改工具

### 一鍵替換腳本

您可以創建一個簡單的批次檔來快速替換圖標：

創建 `quick_icon_change.bat`:
```batch
@echo off
echo 正在備份原始檔案...
copy "src\MonLingo.Core\View\Windows\MainBarWindow.xaml" "MainBarWindow.xaml.backup"

echo 請選擇要替換的圖標主題:
echo 1. 愛心主題
echo 2. 星星主題  
echo 3. 音樂主題
echo 4. 恢復原始

set /p choice="請輸入選擇 (1-4): "

if %choice%==1 goto heart
if %choice%==2 goto star
if %choice%==3 goto music
if %choice%==4 goto restore

:heart
echo 應用愛心主題...
:: 這裡可以添加自動替換指令
goto end

:star
echo 應用星星主題...
goto end

:music
echo 應用音樂主題...
goto end

:restore
echo 恢復原始主題...
copy "MainBarWindow.xaml.backup" "src\MonLingo.Core\View\Windows\MainBarWindow.xaml"
goto end

:end
echo 完成! 請重新建置專案。
pause
```

修改完成後，請檢查：

- [ ] 檔案已保存

- [ ] 路徑數據正確
- [ ] 專案可以建置
- [ ] 圖標正常顯示
- [ ] 功能沒有受影響

## 🆘 問題排除

### 圖標不顯示
- 檢查路徑數據格式
- 確認 x:Key 名稱正確
- 檢查是否有語法錯誤

### 圖標變形
- 調整 Width 和 Height
- 確認 Stretch="Uniform"
- 檢查路徑數據的座標範圍

### 建置失敗
- 檢查 XML 語法
- 確認所有標籤正確閉合
- 恢復備份檔案重新開始
