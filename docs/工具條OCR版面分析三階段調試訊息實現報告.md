# 工具條OCR版面分析三階段調試訊息實現報告

## 📋 實現概述

為工具條版面分析演算法新增了詳細的三階段調試訊息功能，讓開發者能夠即時追蹤每個識別框在三個處理階段中的狀態變化。

## 🎯 功能特點

### ✅ 已實現功能

1. **三階段詳細調試**：
   - 階段一：橫向行合併調試
   - 階段二：智能分欄調試  
   - 階段三：段落分割調試

2. **多重輸出渠道**：
   - 控制台輸出（Console.WriteLine）
   - NLog日誌系統
   - 系統調試輸出（Debug.WriteLine）

3. **自動啟用機制**：
   - 工具條觸發時自動啟用調試模式
   - 無需手動配置調試參數

## 🔧 技術實現細節

### 核心檔案修改

#### 1. `LayoutAnalysisService.cs`

**新增調試方法：**
```csharp
// 階段一調試：記錄識別框合併過程
private void DebugStage1(Rectangle boxA, Rectangle boxB, string stage, string result)

// 階段二調試：記錄分欄檢測過程  
private void DebugStage2(int lineIndex, LayoutLine line, int columnIndex, string reason)

// 階段三調試：記錄段落分割過程
private void DebugStage3(string columnKey, int lineIndex, LayoutLine line, int paragraphIndex, string action)
```

**強化調試輸出：**
```csharp
private void DebugLog(string message)
{
    if (EnableDebugMode)
    {
        // 輸出到控制台和日誌
        Console.WriteLine($"[版面分析調試] {message}");
        Logger.Debug($"[版面分析調試] {message}");
        
        // 同時輸出到系統調試輸出
        System.Diagnostics.Debug.WriteLine($"[版面分析調試] {message}");
    }
}
```

#### 2. `QuickTranslationService.cs`

**啟用調試模式：**
```csharp
var layoutAnalysis = new LayoutAnalysisService();

// 🔍 啟用調試模式以獲得詳細的三階段處理訊息
layoutAnalysis.EnableDebugMode = true;

var layoutResult = layoutAnalysis.AnalyzeLayout(ocrResult);
```

## 🚀 使用方式

### 啟動調試功能

1. **啟動 MonLingo 應用程式**
2. **點擊工具條按鈕**：
   - 按鈕 9：標準OCR + 版面分析（含調試）
   - 按鈕 10：區域選擇 + 版面分析（含調試）
   - 按鈕 11：區域選擇 + 版面分析（含調試）

3. **選擇要分析的區域**
4. **查看調試輸出**：
   - 控制台視窗
   - 日誌文件
   - Visual Studio 輸出視窗（如使用IDE）
