# 第10號與第11號按鈕（Hide / Close）最新進展與成果

更新日期：2025-08-25

## 摘要
- 第10號與第11號按鈕對應右上角的 Hide 與 Close。
- 重點更新：
  - 右上角懸浮區域整合，滑鼠可從「⋯」平滑移動到 Hide / Close 並穩定點擊。
  - 視覺貼齊 bb.png：細藍色虛線框、四角控制點、縮小且貼邊的頂部拖拽膠囊。
  - 僅保留四角控制點，移除四邊中點，減少視覺干擾。
  - 完成框選或右鍵/ESC 後關閉覆蓋層，桌面恢復可點擊；框移交宿主層維持互動。

## 背景與目標
- 過去「⋯」與 Hide/Close 分離，滑鼠移動途中易觸發 MouseLeave 而收起，導致無法點擊。
- 目標：將「⋯」與 Hide/Close 納入單一 hit-test 區域，提升穩定性與可預期性。

## 主要改動（含檔案）
- EnhancedSelectionBox（UI/互動）：
  - `src/MonLingo.Core/View/Controls/EnhancedSelectionBox.xaml`
    - 邊框：細藍色虛線（#6B8AF6，Dash 3,3）。
    - 右上 `SettingsArea`：單一容器（寬 ~80、高 ~22、近透明背景），包含「⋯」與 Hide/Close；
      - MouseEnter：顯示 Hide/Close、隱藏「⋯」。
      - MouseLeave：還原顯示「⋯」。
    - 僅保留四角控制點；移除四邊中點控制點。
    - 頂部中央拖拽膠囊縮小（約 24x10）且貼齊框線，不干擾右上角操作。
  - `src/MonLingo.Core/View/Controls/EnhancedSelectionBox.xaml.cs`
    - 以 FrameworkElement 綁定拖拽手柄/設定區事件。
    - 移除四邊中點控制邏輯；保留四角縮放。
    - Hide：隱藏外觀與控制點；Close：通知宿主層移除控制。

- 覆蓋層/宿主層：
  - `src/MonLingo.Core/View/Windows/RegionSelectionOverlay.xaml.cs`
    - 完成框選：將框交由 `SelectionBoxOverlay` 托管並關閉自身，立即釋放桌面點擊。
    - 右鍵或 ESC：同樣關閉覆蓋層；既有框保留可互動。
  - `src/MonLingo.Core/View/Windows/SelectionBoxOverlay.xaml`、`.xaml.cs`
    - 成為框的全域宿主；僅在框範圍攔截滑鼠，非框區域點穿（WM_NCHITTEST 回傳 HTTRANSPARENT）。

- 日誌（NLog，UTF-8）：
  - 記錄：右鍵攔截、ESC 取消、框選完成、拖拽/縮放與原生訊息攔截。

## 使用行為
- 右上角區域：
  - 懸浮展開 Hide/Close；區域合併避免滑鼠移動時收起。
  - 點 Hide：隱藏框外觀與控制點；點 Close：移除框。
- 拖拽/縮放：
  - 頂部小膠囊可拖動整框；
  - 僅四角可縮放。
- 覆蓋層退出：
  - 框選完成或右鍵/ESC → 覆蓋層關閉；桌面可點擊；框在宿主層可持續操作。

## 驗收重點
- 「⋯」→ Hide/Close 可穩定點擊，移動過程不會收起。
- Hide 會隱藏框外觀與控制點；Close 會移除框。
- 頂部膠囊拖拽與右上角操作不互相干擾。
- 四角縮放正常、四邊中點按鈕不存在。
- 覆蓋層在完成或取消後確實關閉，桌面恢復點擊。
- 多螢幕與高 DPI 下命中/點穿正確（WM_NCHITTEST 使用 Int64 解析）。
