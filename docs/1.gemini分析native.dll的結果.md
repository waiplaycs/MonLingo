一、摘要 (Executive Summary)
Native.dll 是一個 64 位元的原生 C++ 動態連結函式庫，是 Gaminik 應用程式的核心功能引擎。它並未經過加密或加殼保護，其內部結構和程式碼邏輯清晰可見。

該 DLL 主要負責執行高效能和系統底層的任務，這些任務在純 .NET 環境中難以高效實現。其核心職責包括：

高效畫面擷取：利用現代 Windows Graphics Capture API 進行視窗或螢幕的即時影像擷取。

光學字元辨識 (OCR)：提供完整的 OCR 介面，用於從擷取的影像中辨識文字。

資料加解密與驗證：內建加密函式 (AES, MD5, SHA1)，用於保護敏感資料和驗證軟體完整性。

底層系統互動：直接呼叫 Windows API 和 C++ 執行環境來處理日誌、檔案和網路等操作。

總體而言，這個 DLL 是一個精心設計的原生模組，用於分擔主程式 (.NET) 的性能密集型工作。
