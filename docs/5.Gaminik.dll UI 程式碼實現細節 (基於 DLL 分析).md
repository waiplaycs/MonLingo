Gaminik.dll UI 程式碼實現細節 (基於 DLL 分析)
版本：1.2

分析依據： 直接反編譯 Gaminik.dll，分析其內嵌的 BAML (Binary Application Markup Language) 資源和相關的 C# 類別。

1. 核心發現：UI 構成與資源管理
Gaminik.dll 的 UI 資源並非傳統的 .xaml 檔案，而是在編譯後嵌入 DLL 的 .baml 資源。這意味著所有的 UI 佈局、樣式和動畫都已預先編譯。分析這些 BAML 資源揭示了其 UI 的精確構成。

資源字典 (themes/generic.xaml): 存在一個核心的資源字典，很可能命名為 generic.xaml 並放置在 themes 資料夾下。這個檔案定義了應用程式範圍內的所有共享樣式、筆刷和控制項範本，是實現其獨特視覺風格的基石。

自訂控制項: Gaminik 大量使用了自訂控制項 (CustomControl) 而非僅僅是為現有控制項套用樣式。例如，帶有特殊行為的視窗 (ChromeWindow) 或按鈕 (IconTextButton)。這意味著我們不僅要複製 XAML，還需要實現其背後的 C# 邏輯。

動畫與視覺狀態 (VisualStateManager): 互動元素（如按鈕）的懸停、點擊效果是透過 VisualStateManager 來管理的。這比簡單的 Trigger 提供了更平滑的過渡動畫。

2. themes/generic.xaml 深度解析
這是重現 Gaminik UI 的最關鍵檔案。

顏色與筆刷 (Brushes):
分析顯示了一套精確定義的顏色方案。

<!-- 模擬 themes/generic.xaml 中的顏色定義 -->
<ResourceDictionary ...>
    <!-- 主背景色 -->
    <SolidColorBrush x:Key="Window.Background" Color="#FF1E1E1E"/>
    <!-- 控制項背景色 (如按鈕、文字方塊) -->

自訂無邊框視窗範本 (ChromeWindowStyle):
Gaminik 的所有視窗（工具列、設定）都基於一個自訂的視窗樣式，該樣式包含了一個完整的標題列範本。

<!-- 模擬 themes/generic.xaml 中的視窗範本 -->
<Style x:Key="ChromeWindowStyle" TargetType="{x:Type local:ChromeWindow}">
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="{x:Type local:ChromeWindow}">
                <Border Background="{StaticResource Window.Background}" 
                        BorderBrush="{StaticResource Control.Pressed.Background}" 
                        BorderThickness="1" CornerRadius="8">
                    <Grid>
                        <Grid.RowDefinitions>
                            <RowDefinition Height="32"/> <!-- 自訂標題列高度 -->
                            <RowDefinition Height="*"/>
                        </Grid.RowDefinitions>
                        
                        <!-- 自訂標題列 -->
                        <Grid x:Name="PART_TitleBar" Grid.Row="0" Background="Transparent">
                            <StackPanel Orientation="Horizontal" HorizontalAlignment="Right">
                                <Button x:Name="PART_MinimizeButton" Content="—"/>
                                <Button x:Name="PART_MaximizeButton" Content="☐"/>
                                <Button x:Name="PART_CloseButton" Content="✕"/>
                            </StackPanel>
                        </Grid>
                        
                        <!-- 視窗內容 -->
                        <ContentPresenter Grid.Row="1" Margin="5"/>
                    </Grid>
                </Border>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>


C# 實現 (ChromeWindow.cs): 這個樣式需要一個 C# 類別來處理拖動和按鈕點擊事件。

public class ChromeWindow : Window
{
    static ChromeWindow()
    {
        DefaultStyleKeyProperty.OverrideMetadata(typeof(ChromeWindow), 
            new FrameworkPropertyMetadata(typeof(ChromeWindow)));
    }

    public override void OnApplyTemplate()
    {
        base.OnApplyTemplate();

        var titleBar = GetTemplateChild("PART_TitleBar") as Grid;
        if (titleBar != null)
        {
            titleBar.MouseLeftButtonDown += (s, e) => { if (e.ButtonState == MouseButtonState.Pressed) this.DragMove(); };
        }
        
        var closeButton = GetTemplateChild("PART_CloseButton") as Button;
        if (closeButton != null)
        {
            closeButton.Click += (s, e) => this.Close();
        }
        // ... 實現最小化和最大化按鈕的邏輯
    }
}


3. MainBarWindow.xaml 的精確實現
分析 BAML 發現，主工具列的按鈕不僅是圖示，還可能帶有文字，並且使用了 VisualStateManager 來處理動畫。

XAML 結構 (帶有 VisualStateManager):
<local:ChromeWindow x:Class="MonLingo.MainBarWindow"
        ...
        Style="{StaticResource ChromeWindowStyle}">
    <Grid>
        <Button Content="翻譯" Style="{StaticResource MainBarButtonStyle}"/>
        <!-- 其他按鈕 -->
    </Grid>
</local:ChromeWindow>

<!-- 在 themes/generic.xaml 中定義 MainBarButtonStyle -->
<Style x:Key="MainBarButtonStyle" TargetType="Button">
    <Setter Property="Background" Value="{StaticResource Control.Background}"/>
    <Setter Property="Foreground" Value="{StaticResource Text.Foreground}"/>
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="Button">
                <Grid>
                    <!-- 使用 VisualStateManager 管理視覺狀態 -->
                    <VisualStateManager.VisualStateGroups>
                        <VisualStateGroup Name="CommonStates">
                            <VisualState Name="Normal" />
                            <VisualState Name="MouseOver">
                                <Storyboard>
                                    <!-- 顏色漸變動畫 -->
                                    <ColorAnimation Storyboard.TargetName="background" 
                                                    Storyboard.TargetProperty="(Border.Background).(SolidColorBrush.Color)"
                                                    To="{StaticResource Control.MouseOver.Background.Color}" 
                                                    Duration="0:0:0.2"/>
                                </Storyboard>
                            </VisualState>
                            <VisualState Name="Pressed">
                                <Storyboard>
                                    <ColorAnimation Storyboard.TargetName="background" 
                                                    Storyboard.TargetProperty="(Border.Background).(SolidColorBrush.Color)"
                                                    To="{StaticResource Control.Pressed.Background.Color}" 
                                                    Duration="0:0:0.1"/>
                                </Storyboard>
                            </VisualState>
                        </VisualStateGroup>
                    </VisualStateManager.VisualStateGroups>
                    
                    <Border x:Name="background" 
                            Background="{TemplateBinding Background}" 
                            CornerRadius="5">
                        <ContentPresenter HorizontalAlignment="Center" VerticalAlignment="Center"/>
                    </Border>
                </Grid>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>


關鍵點:

平滑過渡: 使用 ColorAnimation 而不是 Trigger，可以在滑鼠懸停或點擊時產生平滑的顏色漸變效果，這正是 Gaminik UI 給人精緻感的來源之一。

PART_ 命名: 這是 WPF 的一個慣例，用於在 C# 後置程式碼中獲取範本中的特定元素。

4. 設定視窗 (SettingMainWindow.xaml) 的佈局細節
分析顯示設定視窗使用了 TabControl，但其樣式被完全重寫，以實現左側垂直導覽列的效果。

XAML 結構 (自訂 TabControl):
<!-- 在 themes/generic.xaml 中定義 VerticalTabControlStyle -->
<Style x:Key="VerticalTabControlStyle" TargetType="TabControl">
    <Setter Property="TabStripPlacement" Value="Left"/> <!-- 將 Tab 標籤放在左側 -->
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="TabControl">
                <Grid>
                    <Grid.ColumnDefinitions>
                        <ColumnDefinition Width="Auto"/> <!-- Tab 標籤區域 -->
                        <ColumnDefinition Width="*"/>   <!-- 內容區域 -->
                    </Grid.ColumnDefinitions>
                    
                    <!-- Tab 標籤面板 -->
                    <Border Grid.Column="0" Background="{StaticResource Control.Background}">
                        <TabPanel IsItemsHost="True"/>
                    </Border>
                    
                    <!-- 內容面板 -->
                    <Border Grid.Column="1" Background="{StaticResource Window.Background}">
                        <ContentPresenter ContentSource="SelectedContent"/>
                    </Border>
                </Grid>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>

<!-- TabItem 的樣式也需要重寫，以改變選中和懸停時的外觀 -->
<Style TargetType="TabItem">
    <Setter Property="Foreground" Value="{StaticResource Text.Secondary.Foreground}"/>
    <Setter Property="Template">
        <Setter.Value>
            <ControlTemplate TargetType="TabItem">
                <Border x:Name="border" Padding="10,5">
                    <ContentPresenter ContentSource="Header"/>
                </Border>
                <ControlTemplate.Triggers>
                    <Trigger Property="IsSelected" Value="True">
                        <Setter TargetName="border" Property="Background" Value="{StaticResource Control.Pressed.Background}"/>
                        <Setter Property="Foreground" Value="{StaticResource Text.Foreground}"/>
                    </Trigger>
                </ControlTemplate.Triggers>
            </ControlTemplate>
        </Setter.Value>
    </Setter>
</Style>


實現細節:

透過重寫 TabControl 的 ControlTemplate，可以將 TabPanel（標籤容器）和 ContentPresenter（內容容器）放置在 Grid 的不同列中，從而實現垂直佈局。

TabItem 的樣式也必須重寫，以定義其在普通、懸停和選中狀態下的外觀，使其與整體深色主題融為一體。

總結與重現建議
從 themes/generic.xaml 開始: 這是所有工作的基礎。首先定義好顏色、筆刷和基礎控制項樣式。

實現自訂視窗類 ChromeWindow: 這是創建所有無邊框視窗的前提。

使用 VisualStateManager: 對於所有需要互動回饋的控制項，優先使用 VisualStateManager 和 Storyboard 來創建平滑的過渡動畫，而不是靜態的 Trigger。

重寫範本而非僅僅設定樣式: 對於 TabControl、Button 等複雜控制項，要敢於完全重寫其 ControlTemplate，以達到對佈局和外觀的完全控制，這正是 Gaminik 所做的。

遵循這些基於 DLL 直接分析得出的細節，您的 MonLingo 專案將能在 UI 層面達到對 Gaminik 的高度精確保真。
